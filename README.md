# #AlémDoAgora — Blog

Esse projeto apresenta o artigo **“#AlémDoAgora: O lado da carreira que as redes sociais não mostram”**, com uma página responsiva e identidade visual inspirada nos tons da logo da DIO para postagem do segundo desafio do Campus Expert #17.

Ele foi criado para compartilhar reflexões sobre carreira, tecnologia, aprendizado e os desafios que fazem parte da trajetória profissional — inclusive aqueles que nem sempre aparecem nas redes sociais.


## ✨ Funcionalidades

- Página de leitura responsiva para desktop e dispositivos móveis.
- Artigo dividido em seções, com navegação pelo conteúdo.
- Identidade visual própria, com cores e elementos gráficos personalizados.
- Metadados da página configurados para compartilhamento e identificação do site.
- Conteúdo do artigo separado da estrutura da página, facilitando futuras edições.

## 🚀 Executar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) 20.9 ou superior
- npm (incluído na instalação do Node.js)
- Git, caso queira versionar o projeto

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/alem-do-agora-blog.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd alem-do-agora-blog
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inici[e o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse [http://localhost:3000](http://localhost:3000) no navegador.](https://alem-do-agora-blog.vercel.app/)
